Overview

Synth Stocks Play is a stock trading simulation platform that helps users practice investing without using real money. It provides a safe and interactive environment to understand market behavior, test strategies, and improve decision-making skills.

Problem Statement

Entering the stock market is difficult for beginners because:
 No real-world experience
 Fear of financial loss
 Complex and overwhelming platforms 
 As a result, many people avoid investing altogether.

Our Solution

We built a risk-free, beginner-friendly trading simulator that:

Allows users to trade with virtual money
Provides performance insights
Encourages learning through real interaction

Key Features

1 Stock Trading Simulation
Buy and sell stocks using virtual currency
Experience real market-like behavior
2 Portfolio Management
Track investments, profit, and loss
Monitor overall portfolio performance
3 Smart Chat/Search
Explore stock-related queries
Get quick insights within the platform
4 Biweekly & Monthly Analysis
Track performance every 2 weeks and monthly
Identify trends and improve strategies
Build long-term investing discipline
5 Interactive Dashboard
Clean, intuitive, and beginner-friendly UI
Real-time-like updates

Frontend	React (TypeScript)
Styling	CSS
Runtime	Node.js / Bun
Testing	Playwright
